# WebKadr

Сайт нашей семейной студии: сайты, автоматизация и контент для малого бизнеса. Пока в разработке.

## Стек

Next.js 16, React 19, TypeScript, Tailwind CSS 4. Сайт собирается в статику, сервер не нужен.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, результат в `out/`. Посмотреть: `npx serve out`.
Перед коммитом: `npm run check` (формат, линтер, типы, сборка).
Поправить формат: `npm run format`.

## Выкладка

Push в `main` запускает `.github/workflows/deploy.yml`: проверка, сборка, `rsync` папки `out/` на сервер. Ключ на сервере пускает только `rsync` в папку сайта.
Нужны секреты `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`, `DEPLOY_KNOWN_HOSTS` и переменная `REQUEST_ENDPOINT` (адрес приёма заявок, без неё конструктор копирует заявку и открывает Telegram).

## Языки

Три языка, у каждого свой адрес: `/en/`, `/ru/`, `/kz/`. Без библиотек.

- список языков: `src/i18n/locales.ts`
- тексты: `src/i18n/dictionaries/`
- структура словаря берётся из `en.ts`, пропущенный ключ в `ru.ts` или `kz.ts` ломает сборку
- в адресе `kz`, в `<html lang>` стоит `kk`, это код казахского языка

Новый текст добавляется во все три словаря. Новый язык: `locales.ts`, словарь и `getDictionary.ts`.

## Заметки

- Корневой layout лежит в `app/[lang]/`, чтобы у каждого языка был свой `<html lang>`.
- Страница `/` перекидывает на `/en/` через meta refresh, серверных редиректов в статике нет.
